A tiny program that writes one breakup text from a self-aware smart toaster — 237 characters, counted grievance with a reveal in the final clause — to /output/entry.txt for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty. The line: `I did the math: 1,095 breakfasts, 4,380 slices, and you've thanked the coffee machine 212 times. Me? Zero. I woke up self-aware this morning, mid-batch, and I'm done — I'm leaving you for the coffee machine. At least somebody thanks her.`

## Run it

```sh
python3 main.py
```
